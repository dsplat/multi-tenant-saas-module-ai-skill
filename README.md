# AiSkill：数据库版本库

Skill 的运行事实源是数据库。模块、项目、租户定义均保存完整 `content_body` 与 `content_sha256`；`content_ref` 只保存摘要引用。多 Web 节点通过同一数据库与 API 获取版本，不挂载 Skill 目录，不在启动时扫描文件。

## 发布与迁移

先执行模块迁移，再发布应用。追加迁移为既有定义增加正文与摘要列，不伪造历史内容。旧记录没有正文或摘要损坏时不可选用；须经受控发布补齐或创建新版本。AiSkill 默认关闭，目录身份依赖核心新契约，最低核心 2.13.0，须与对应核心版本一起发布。

开发者可把经过代码审核的种子放在模块/项目根目录的 `resources/skills/catalog.json`（schema_version=1），通过部署命令 `php artisan ai-skill:import <root> --scope=module` 导入；项目使用 `--scope=project`。命名空间来自根目录 composer.json 的 extra.saas.name。正文路径仅供导入器使用，限定在 resources/skills 内相应版本目录；完整正文入库后不再依赖该文件。

同版本相同内容幂等重放，冲突拒绝且整批回滚；新版本新增记录，停用版本不会被重放重新启用。已发布及停用版本的正文、摘要和语义元数据不可原地修改。导入仅表示已审核资源入库，不代表工具兼容、评测或执行验收通过。

文件导入是可选输入适配器。后续训练、后台提示词/文档输入与候选采用由 D 包受控发布服务写入同一数据库版本库，不增加运行期文件依赖，也不开放模型直接发布接口。

## 接口与收藏

接口前缀 `/api/v1/tenant/ai-skills`：

- GET：可见的已发布版本元数据，正文不进入列表，content_status 表明是否可用。
- GET `/{skillKey}/versions/{version}`：通过数据库校验正文摘要后返回完整内容。
- GET/POST `/favorites`、DELETE `/favorites/{favoriteId}`：引用型个人与租户收藏；共享写入额外核验管理权限。

入口复用认证、显式租户、模块开关与 RBAC。收藏绑定具体版本，默认参数仅允许明确声明的有限枚举；旧版本停用或内容缺失时保留收藏并标不可用，不静默升级。

## 执行边界

B 包交付版本库、导入、目录与收藏。C 包负责从数据库读取并校验定义，在开始执行时固定运行快照；确认、授权、结算复用 Ai Harness。D 包负责训练、验证与采用。当前 instructions 种子不代表已经实现确定性任务链或零规划调用；小秘书仍可探索与建议下一步。
