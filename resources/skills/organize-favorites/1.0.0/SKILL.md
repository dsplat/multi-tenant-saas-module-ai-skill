# 整理任务收藏

目标：让运营人员看清自己的任务收藏与租户共享收藏，识别失效引用，并形成整理建议。

1. 使用已授权的当前 Operator 和明确租户读取收藏目录；不读取其他人员的私人收藏。
2. 将个人与租户共享收藏分开展示，保留 skill_key、version 和引用状态。
3. 对失效、歧义或参数不兼容的引用解释原因；不得用新版本静默替换旧版本。
4. 按用户选择的 compact/full 展示方式输出整理建议。不要自动删除、采用、执行或修改收藏。
5. 将是否修改、是否升级的选择交给用户。任何后续写入仍走收藏服务的授权与参数校验。

成功判据：清楚列出两种范围和失效原因，用户能决定保留、移除或显式升级，没有发生未授权写入。

此版本是可供人员或助手阅读的方法说明。instructions 不是固定链；Harness 执行接线由执行包完成，不能宣称零规划调用或已训练出业务收益。
